# Neon Rogue Run

A small touch-friendly web action game optimized for mobile (iPhone). Controls: on-screen touch buttons for left/right/jump/shoot. Saves progress (player position, score) to localStorage.

How to run
1. Open `index.html` in your mobile Safari or desktop browser.
2. Use the on-screen buttons to control the player.

Files
- index.html — game host
- style.css — mobile-friendly styling
- main.js — game engine (canvas), touch controls, save/load
- assets/ — place for images/sounds (currently none)
