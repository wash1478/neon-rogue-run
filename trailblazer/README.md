# Trailblazer — Bike Runner Prototype

A mobile-first HTML5 side-view bike runner. Arcade physics: speed, jumps, aerial tricks, holes to avoid, prairie dogs crossing. Three themed level sets: Forest, Beach, Manhattan.

Run locally:
1. cd trailblazer
2. python3 -m http.server 8000
3. Open http://<host-ip>:8000 on your device

Controls:
- Left joystick: lean/steer
- Right buttons: accelerate, jump, trick

Features in this prototype:
- Side-scrolling bike with jump physics
- Random holes (avoid) and prairie-dog hazards
- Ramps for airtime and trick scoring
- Score = distance + airtime + trick combos
